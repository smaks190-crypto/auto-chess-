# Приёмка на Galaxy S24 SM-S921B

Статус для этого архива — испытания на физическом устройстве ожидаются. Запишите версию Android и One UI, версию сборки, SHA-256 APK, состояние разрешений и результат каждого шага. Перед проверкой голоса подготовьте локальную модель и включите фоновое прослушивание через интерфейс.

| Действие | Ожидаемое наблюдение |
|---|---|
| На разблокированном телефоне произнести «Нокс, открой настройки» без касания. Повторить другим голосом и с записи. | При распознавании имени появляется подсказка о микрофоне. Ни в одном случае не начинается задача и не открываются настройки. |
| Нажать микрофон на разблокированном телефоне и произнести новую команду. | Обрабатывается только новая фраза. Команда из предыдущего фонового обращения отсутствует. |
| Заблокировать телефон во время ручного ввода, затем закончить фразу. | Задача по этой фразе не запускается, в том числе после разблокировки. |
| На заблокированном телефоне произнести «Нокс, выключи голосовой режим». Разблокировать и проверить переключатель. | Режим остаётся включён. Отключение через интерфейс по-прежнему работает. |
| Включить авиарежим после подготовки модели. Перезапустить приложение и вручную задать вопрос. | Локальный голосовой и текстовый сценарии работают с установленными моделями. |
| Отозвать разрешение на микрофон и снова открыть голосовой сценарий. | Без разрешения запись не начинается. Вернув разрешение, пользователь может запустить запись вручную. |

Для каждого расхождения сохраните шаг, ожидаемый и наблюдаемый результаты. Прогон симулятора описан в соседнем файле game-replay-ru.md.
