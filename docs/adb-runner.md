# ADB Runner development interface

Only src/dev contains the diagnostic provider and clipboard activity. Both require the platform DUMP permission; the provider additionally checks UID 2000 and exposes only a fresh snapshot of the visible, unlocked N.O.X Dev window, excludes password nodes, bounds work and returns failure if incomplete. No cross-app export, arbitrary action execution, network listener or clipboard read. The visible clipboard activity writes only the explicit UTF-8 text supplied by the authorized caller, logs a random operation token and result (not text), then finishes. The client must verify foreground and target field and verify paste; never send automatically. Clipboard contents may remain in Android keyboard history. Device verification required before enabling fast path.
