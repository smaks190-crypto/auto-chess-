# Проверка фаз игры в автономном симуляторе

Из корня проекта запустите в среде Android-сборки из `.github/workflows/android.yml`:

```bash
gradle :app:testDebugUnitTest --tests 'dev.nox.local.game.PreparationAdvisorTest'
```

Тесты используют фиксированные наблюдения. Магазин, золото, место на скамье и состав уже заданы во входных данных. Подключать телефон, давать разрешения или запускать игру для этой проверки не требуется.

| Наблюдение | Ожидаемый результат |
| --- | --- |
| Бой, раунд 2, наблюдение 10 | Рекомендации о покупке нет. |
| Подготовка, наблюдение 11. Доступно 3 золота и 1 место. Scout стоит 4, Guard стоит 2 | Из списка приоритетов выбран доступный Guard за 2. |
| Подготовка, наблюдение 12. Осталось 1 золото, ячейка Guard опустела, состав пополнился Guard, скамья заполнена | Покупка подтверждена. Следующей рекомендации нет. |

Отдельные проверки покрывают неизвестную фазу, отсутствие подходящей покупки, нехватку золота и свободного места, пропущенные наблюдения и противоречивые эффекты покупки. Номера наблюдений последовательны внутри сценария. Подтверждение относится к одной покупке без объединения героев и без одновременных изменений магазина.

Это проверка логики на структурированных данных. Качество OCR, модель выбора стратегии и распознавание фаз по реальному видеоряду требуют собственных испытаний. Симулятор доступен через указанную тестовую команду.
